# Agentic DocSync Capstone - Documentation

This directory contains all documentation for the GitHub Copilot Capstone project demonstrating an **Agentic SDLC Pipeline**.

## Directory Structure

```
docs/
├── README.md          # This file
└── sdlc/              # SDLC artifacts (created during workflow)
    ├── requirements.md
    ├── architecture.md
    ├── design-review.md
    ├── impl-plan.md
    ├── code-review-report.md
    ├── verification-report.md
    └── pr-description.md
```

## SDLC Artifacts

The `sdlc/` directory will contain artifacts generated by each agent during the workflow:

| File | Agent | Stage | Description |
|------|-------|-------|-------------|
| `requirements.md` | requirements-agent | 1 | Structured requirements from PRD |
| `architecture.md` | architecture-agent | 2 | System design and component structure |
| `design-review.md` | design-review-agent | 3 | Security and quality review |
| `impl-plan.md` | planning-agent | 4 | Task breakdown with dependencies |
| `code-review-report.md` | code-review-agent | 6 | Code quality assessment |
| `verification-report.md` | verification-agent | 7 | Test results and coverage |
| `pr-description.md` | pr-agent | 8 | Pull request description |

## Workflow

The SDLC workflow progresses through 8 stages:

```
PRD → Requirements → Architecture → Design Review → Planning →
Implementation → Code Review → Verification → PR
```

**Human Approval Gates:**
- After Architecture (Stage 2)
- After Design Review (Stage 3)
- After Code Review (Stage 6)
- PR Merge (Stage 8)

## How to Use

1. **Start the workflow:** Use sdlc_orchestrator to begin
2. **Review artifacts:** Each stage produces a document in `sdlc/`
3. **Approve at gates:** Human reviews and approves before proceeding
4. **Track progress:** Git commits show stage progression

## Traceability

All artifacts reference their source and next stage, providing full traceability from PRD to merged PR.
